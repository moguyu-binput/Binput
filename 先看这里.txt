# 柄输 1.0.1 —— 手柄九键输入法

（内部名 GamepadT9。给游戏里用手柄打中文用，主要场景是 FF14。）

**两个版本：预输入版 / 直出版。** 在设置里切，随时可换。

---

## 一句话思路

以前想“不让游戏读到手柄”（HidHide / ViGEm，都卡住了）。
现在改成 **“让游戏失去焦点”** —— 唤出键盘时把我们的窗口顶成前台，
游戏失焦后自己就不吃手柄了（FF14 设置里的“失焦手柄失效”正是这个前提）。

字怎么打，**两个版本完全一样**：

- **九键**：只把数字解成拼音（`7468326` → `shou'dao`），发给系统输入法，
  **汉字、词组、联想全部由系统输入法给** —— 我们不再自己出词
- **26 键**：纯英文，字母直接投递，不走输入法

**两个版本唯一的区别是“字去哪儿”**：

| 版本 | 界面 | 字去哪儿 |
| --- | --- | --- |
| **预输入版** | 前台窗口，上面有**记事本预览框** | 先打在预览框里，收起时整段复制 + 粘进游戏 |
| **直出版** | 不抢焦点、没有预览框 | 按键**直接送到当前有焦点的窗口** |

用哪个看你场景：FF14 里一般要**预输入版**（一句话打完再发，游戏不会吃到半截按键）；
普通 Windows 窗口里打字用**直出版**更顺手，跟用键盘没两样。

---

## 哪些手柄能用

**Xbox 手柄和 PS5 手柄都行。** 界面上写的按键名一律按 Xbox 的叫法（A / B / X / Y、
LB / RB、Back / Start），PS5 手柄按下表对应：

| PS5（DualSense） | 程序里当 | PS5（DualSense） | 程序里当 |
| --- | --- | --- | --- |
| ×（下面那颗） | **A** | L1 / R1 | LB / RB |
| ○（右边那颗） | **B** | L2 / R2 | LT / RT |
| □（左边那颗） | **X** | 左摇杆按下 / 右摇杆按下 | L3 / R3 |
| △（上面那颗） | **Y** | **Create**（触摸板左边那颗） | **Back** |
| 十字键 / 摇杆 | 一样 | **Options**（触摸板右边那颗） | **Start** |

四颗功能键是**按位置**对的（PS 的 × 在最下面，Xbox 的 A 也在最下面），
所以“下面那颗 = 确定”的肌肉记忆不用改。**PS 键和触摸板按下不参与** ——
PS 键在 Windows 上一按会弹 Xbox Game Bar，拿它干活是自找麻烦。

插线、蓝牙都行，不用装 DS4Windows / Steam，也不用把 Steam 开着。

**Switch Pro 也是按位置对**：底下那颗 = **A**、右边 = **B**、左边 = **X**、上边 = **Y**；
L / R = LB / RB、ZL / ZR = LT / RT、**− = Back、+ = Start**（2.4.3 起，之前是按符号对的）

- **能直接用**：Xbox 360 / One / Series 原装；第三方手柄**拨到 XInput 档**
  （8BitDo 的 X 档、飞智 / 盖世小鸡 / 北通等的 X 档、罗技 F310 拨到 X）；
  **PS5 DualSense**、**Switch Pro 手柄**
- **多半也能**：PS4（DualShock 4）等 —— 只要 **Windows 自己认得**这只手柄
  （设置 → 蓝牙和设备 → 游戏控制器里能看到、网页手柄测试能亮），我们就能用
- **插好几只手柄也行，但同一时刻只听一只：谁在动听谁的。** 拿起一只按一下就
  接管，放下换另一只也能接着用，再换回来还行；松手两秒内还是认刚才那只。
  没人动的时候摇杆一律当 0 —— 某只手柄摇杆卡住了也不会拖累别人
- **不能用**：第三方手柄拨到一些冷门档位、或者 Windows 压根不认的老设备

判断标准很简单：**Windows 认得它，我们就认得它**。程序用的是和网页手柄测试
同一套接口（Windows 自带的 Windows.Gaming.Input），按键映射是微软做的，
不是我们自己猜的。

## 怎么用

1. 双击 `GamepadT9.exe`（屏幕上看不到东西是对的，它只待在右下角托盘）
   · **已经开着再双击一次不会开第二份**，只会把正在跑的那个唤出来
     （关掉它请走托盘右键 → 退出）
2. 进设置有三种办法，进去之后都一样：
   · 托盘右键 → **设置...**
   · 键盘唤出后点右下角的小齿轮
   · **长按 Y 约 1 秒**（右手拇指那颗，别松手）—— 界面会像翻卡片一样翻到背面的设置页
     在设置页里 **再长按一次 Y** 就翻回键盘正面
     （2.3.2 之前是单按 R3，那颗在摇杆底下，手正推着摇杆选键的时候够不着）
   · 第一个区块就是**版本**：预输入版 / 直出版
   · 设置页里**十字键改成选设置项、A 确认**：上下在项之间走，
     **左右在主题那八个色块之间挑**；光标所在那一项会闪一下琥珀色边框。
     不再代表键盘方向键；**B** 返回
3. 按 **L3 + R3**（两个摇杆垂直按下去）唤出键盘
4. 打字 —— 九键：`7468326` → **十字键 ←/→** 挑拼音 → **RB** 整段发给输入法
   → **十字键 ←/→ 选词、↑/↓ 翻页**（发出拼音后，十字键就等于键盘方向键，
     候选窗是系统输入法的，选词交给它）
   → **再按一下 RB** 空格上屏（两个键连着按，手不用换位置）
   （两个字可以一次发完，不用一个字一切；九宫格只能用**摇杆**选，十字键只管拼音）
   · **A 只用来输入数字**，不当确认键（**RT 就是回车**）
   · 换切分用 **十字键 ←/→**，挑中并按 **RB** 发出去之后，这条拼音就被记住了 ——
     下次同样这几个数字它自动排第一（存在 `%LOCALAPPDATA%\GamepadT9\pinyin.txt`，
     设置 → 输入习惯 可以清掉）
   · 拼音候选永不为空：拼一半出半截拼音（`7` → p q r s，`94` → yi zi xi），
     怎么拼都不是音节时出字母兜底（`4444` → gggg gggh …），不会留一片空白
   · 拼音行摆几个按拼音实际长度量出来，短的多摆、长的少摆；
     **→** 走到最后一个再按一下会展开成“全部拼音”网格，**B** 返回
   · **整段联想都不对时按 Y 只定住第一个字**（有拼音的时候 Y 就是切分，按下立刻生效），剩下的数字会自动重新切出第二个字的读音
     （**九宫格的 1 号键没有功能**，是画暗的 —— 它在角上，摇杆选键时最容易扫到，
     留着就是手一抖把刚打好的拼音切一刀。切分一律走 Y）
   · **X 只删除，不退出**（在“全部拼音”/“全部符号”里按 X 还留在原地），
     要退出按 **B**
   · 符号面板分**八类，每类 40 个**（常用 / 中文 / 英文 / 数学 / 箭头 / 数字 /
     单位 / 图形），**LB / RB** 换类；右摇杆推到右下角“更多”停一下唤出
   · **RT 按一下 = 回车**（不用长按，右下角那根长按进度条已经删了）
5. **26 键（没有拼音的时候按一下 Y 切换）**= 一整块笔记本键盘：数字行、F1~F12、Tab / Caps / Shift /
   Ctrl / Alt / Win / 回车 / 退格 / 方向键全都在
   · 换过去 / 换回来**也带翻面动画**（宽度一下从 360 变 640，压扁换完再展开）
   · **按住 LB = 按住 Shift** —— 打字母是大写，打数字键出 `! @ # $ % ^ & * ( )`
   · **Ctrl / Alt / Win** 按一下“粘住”，再按下个键就一起发出去（比如 Ctrl+C）
   · **用摇杆选键**（十字键在 26 键同样只当方向键），**A** 按下
   · 切到全键盘后，预览框会跟着键盘变宽并**贴着键盘上沿**
6. 按 **L3 + R3** 收起
   · **预输入版**：自动复制 + 按档位粘进游戏
   · **直出版**：只是收起界面，没有复制粘贴这回事
   · 用鼠标点了别的窗口：键盘会自动收起（**不复制**），打了一半的字留着，
     再按一次 **L3 + R3** 就唤回来，不用先关再开

**收起后的四档**（设置 → 收起后）—— **只有预输入版用得上**：
仅复制 / 复制+粘贴 / 复制+粘贴+回车 / **FF14（先回车开聊天框再粘贴）**
（直出版没有预览框，也就没有“收起时复制粘贴”这一步，这四档会自动置灰。）

> **游戏里怎么都没反应？先把柄输改成以管理员身份运行。**
> 游戏要是“以管理员身份运行”的而柄输不是，Windows 会把柄输发过去的键
> **一个不剩地静默丢掉** —— 不报错、不弹窗，就是没反应。两边权限一样高才行。
> 日志里 `完整性` 那一行会直接写出来（后面跟 `!!` 就是这个问题）。

详细键位和排错看 `版本说明.md`。

## 托盘右键菜单

- 显示 / 隐藏键盘
- **设置...**
- 退出

设置页不再单独弹窗，而是直接翻到当前键盘界面的背面。
翻到背面后：

- 点右下角的 **← 返回箭头** 回到键盘正面
- **长按右下角齿轮（约 0.3 秒）再挪动** 可以移动整个界面的位置
  （单击只翻面、不移动；背面返回箭头只管点击，不能拖）
- 鼠标放到齿轮 / 返回箭头上，图标会**放大一点**表示可以点
  （**不画高亮方块，也不变色** —— 只有放大）
- 所有改动立刻生效并自动保存：版本、收起档位、摆位都记在
  `%LOCALAPPDATA%\GamepadT9\`，下次启动自动恢复
- 设置那一栏内容多了可以往下滚，滚动条是一条细的半透明圆角条
  （不是系统那个灰白方块）
- **界面缩放**不做滑块了：**设置 → 键盘 → 「调整窗口」**点一下就进“缩放/摆位”模式，
  十字键 **↑ / ↓** 缩放，**摇杆**挪位置，**按 B 存好退出**
  （2.3.3 之前是按住 R3，那颗键在摇杆底下，手推着摇杆选键时够不着，
  而且得一直摁着，一松手就退出去了）

设置项按区块排布：版本、收起后（预输入版）、**主题**、**动态效果**、
输入习惯、维护工具（打开日志 / 打开数据目录 / 关于 / **退出程序**）。

**主题**：八个带对应颜色边的方块，**每个方块都是一个独立选项**。
鼠标点哪个就换成哪个；手柄上 **十字键 ← / → 在八个方块之间挑**，
上下会整排跳过（不会让你按八次才走过主题），按 **A** 换上当前挑中的那套。
八套都是低饱和度的深色（原色 / 灰 / 黑 / 红 / 蓝 / 绿 / 黄 / 粉），
**透明度一律和原色一样**（面板 E8），换的只是色相，字色和高亮不动。
选的这套记在 `%LOCALAPPDATA%\GamepadT9\theme.txt`。

**动态效果**：开的时候，当前焦点那颗键会**弹一下、微微放大、带点影子**，
像是浮在旁边的键上面（只放大一点点，刚好压住邻居，不会挡住字）。
九键 / 全键盘 / 候选行 / 符号格子 / 数字层的 0 **都会这样**。
同时**九键那根摇杆线会整层消失** —— 焦点在哪纯看哪颗键凸出来；
**不动左摇杆就是中间的 5 凸出来**。关掉就回到原来的“高亮描边 + 摇杆线”。
开关记在 `%LOCALAPPDATA%\GamepadT9\fx.txt`，**默认是开**。

> **Y 五种活别混**：**有拼音的时候按下就是切分**（不等松手）；
> **没拼音的时候按一下 = 换九键 / 全键盘**，**按住满半秒（500 毫秒）= 进 / 出设置**；
> **数字层里按一下 = 出 0**；**窗口F 绑数字那一层按一下 = 解除绑定**。
> **L3 / R3** 现在彻底闲着（出 0 / 解绑归了 Y，调界面搬到设置页了），
> 只剩 **L3 + R3** 唤出 / 收起键盘——它们也可以在设置里各自被定成唤出键。

## 两个包的区别

- `GamepadT9-Game-x64-selfcontained\` —— **自带 .NET 运行时**，拷到任何 64 位 Win10/11 都能跑，exe 约 64MB
- `GamepadT9-Game-x64\` —— 只有 7MB，但要本机装有 **.NET 8 桌面运行时**

`dict.txt` 现在是一张**拼音表**（每行一个成词的拼音串，46389 条），
只用来判断“这串拼音像不像一句人话”，好把 `shou'dao` 这种排到 `shou'da'o` 前面。
里面**一个汉字都没有** —— 汉字由系统输入法出，所以文件从 943KB 瘦到了 412KB。

日志在 `%LOCALAPPDATA%\GamepadT9\log.txt`（Win+R 粘贴这个路径回车，
或者双击 `打开日志.cmd`）。只记关键节点，**超过 200KB 自动砍掉前半截**，
不会越滚越大。
